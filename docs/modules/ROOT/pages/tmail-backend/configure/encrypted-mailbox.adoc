== Enabling/Disabling the encrypted mailbox

Encrypting messages is costly thus we understand an administrator might choose not to enable this feature.

We provide an easy way to disable completely the **Encrypted Mailbox** through the configuration.

One need to load the corresponding extension Guice modules in order to use the feature:

....
com.linagora.tmail.james.app.DistributedEncryptedMailboxModule
com.linagora.tmail.james.app.PostgresEncryptedMailboxModule
com.linagora.tmail.james.app.MemoryEncryptedMailboxModule
....

== Number of PGP public keys per user

Each message appended to an encrypted mailbox is encrypted for every public key of its owner. The number of
public keys a user can store is thus bounded, by default to 10. The `tmail.keystore.max.keys.per.user` JVM
system property overrides this limit, for instance in `jvm.properties`:

....
tmail.keystore.max.keys.per.user=10
....

== Deleting the encrypted projection

The encrypted projection of a message (encrypted preview, bodies and attachments) is deleted along with the
message by a pre-deletion hook. It needs to be declared in `listeners.xml`:

....
<listeners>
    <preDeletionHook>
        <class>com.linagora.tmail.encrypted.DeleteEncryptedProjectionHook</class>
    </preDeletionHook>
    <!-- ... -->
</listeners>
....
