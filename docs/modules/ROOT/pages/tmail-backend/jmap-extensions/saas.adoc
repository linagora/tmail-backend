= Software As A Service (SaaS) JMAP Extensions
:navtitle: SaaS

== Additions to the capability object

Servers supporting the Twake Workplace SaaS integration need to advertise it through the session capabilities:
....
com:linagora:params:saas
....

The associated object has the following fields:

- `canUpgrade`: *Boolean*. True if the user can upgrade to a higher plan.
- `isPaying`: *Boolean*. True if the user is currently on a paying plan.
- `mailDnsConfigurationValidated`: *Boolean*. False while the user's domain awaits mail DNS
validation: the <<_domain_dns_status,mail DNS sending controls>> then reject outgoing mail
from this account.

== Domain DNS status

SaaS domain DNS events supply `mailDnsConfigurationValidated`, which is persisted in the
domain table. Ownership verification allows domains to be provisioned for migration before
mail DNS configuration is complete. Subscription-only events do not overwrite DNS status.

See xref:tmail-backend/configure/mail-dns-sending-controls.adoc[Mail DNS sending controls]
for the required JMAP and SMTP guards and their configuration.
